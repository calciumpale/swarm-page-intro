## 实际观察

GIF 中 0 秒是完整 Stripe 页面；约 1 秒页面淡空、彩色光标向中心图标靠拢；约 2.5 秒光标环绕成群；约 4.5 秒已开始多处并行重建，蓝色选框和尺寸牌跟着拖动，出现标尺、参考线、正在输入的文字；约 7 秒首屏主体基本恢复；10 秒左右继续随页面向下构建。时间只描述该演示抽样，不是通用插件参数。

它的趣味来自“真实内容被工具操作造出来”，不是无目标的鼠标漂浮。画面有很短的未完成状态：灰色占位、选中边界、输入游标、对齐线，随后转为原来的网页。光标可并行，但内容有依赖顺序。

作者说明还列出：标题从小字号逐级放大、按住 Option 拖拽复制、鼠标群对真实鼠标的群集响应、随滚动增加代理、Tour 自动滚动、速度切换、合成音效。此次 GIF 抽样不足以逐项确认上述细节，按作者文档记载。

## 网站开场的改编

用户要求首屏约 6 秒，并根据项目内容复杂度动态调整；效果随页面滚动继续，停在半页时只完成当前可见部分，等下一次滚动才接着构建。

因此使用按视口推进的轻量实现：页面主体保持原样，所选内容在原位置被视觉揭示；用户不安装扩展。当前内容完成后光标退场，真实内容可交互；未访问内容等待，整个站点不等待动画 promise。

建议普通首屏节奏（约 6 秒，仅作为编排参考）：

| 阶段 | 大致占比 | 看见什么 |
| --- | --- | --- |
| 聚集 | 前 5–10% | 光标绕 logo / 中心聚集后分工 |
| 基础 | 10–40% | 容器选框展开，尺寸数字与对齐线 |
| 填入 | 25–85% | 标题、正文、图片、按钮并行完成 |
| 重复 | 50–95% | 母版到目标的复制轮廓与内容替换 |
| 暂歇 / 结束 | 最后 5% | 光标撤走；当前区域正常使用，等待继续滚动 |

时长由**本批可见内容**的目标数量、字数、父子依赖、并发数估算。简单区域约 3–4 秒，普通视口 5–7 秒，复杂视口 8–12 秒；以实际运行时范围和浏览器测量为准。后续只有一个小目标进入视口时不强行再播完整 6 秒。

滚动只是解锁新内容，不是退出手势；不自动滚页，也不等用户到达页面底部才开始播放。出屏任务暂停进度，已完成内容回看不重复。下一段开始前重新测量窗口/内部滚动容器的实际坐标。移动端减少光标数量，节奏仍由复杂度决定。

## 配色和图形

界面本身保持项目品牌色。光标可采用蓝、橙、紫、绿等高可辨认颜色，每个光标颜色固定；标签小而简短。选框用细完整轮廓与角点；尺寸值跟随当前拖框尺寸，不写死。guides 是短暂功能参考线，结束全部移除。不要把参考线做成卡片左侧装饰性强调条。

## 诚实的相似度

所附 runtime 是“真实 DOM 原位揭示 + 设计工具覆盖层”的轻量版。它不解析任意网站、不截图冻结媒体、不生成上千图层，也不等同真实编辑器中的逐字输入或复制 DOM。短文本使用逐字视觉节奏，多行文字需按实际测量或单行目标处理。精确效果以 `assets/swarm-intro.js` 和浏览器观察为准，不能把 README 中完整原版能力当成已实现。
